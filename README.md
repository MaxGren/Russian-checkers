# Русские шашки

**Игра шашки на C# и .NET 10**

Настольное приложение для игры в русские шашки против компьютера с графическим интерфейсом WPF, системой учётных записей и локальной базой данных SQLite.

Компьютерный соперник использует алгоритм **Minimax с альфа-бета-отсечением**. Приложение поддерживает сохранение незавершённых партий, просмотр истории ходов и экспорт игрового протокола в текстовый файл.

---

## Возможности

**Игровой процесс**
- Игра против компьютерного соперника.
- Правила русских шашек на доске 8×8.
- Обязательное взятие шашек противника.
- Поддержка последовательных взятий и дамок.
- Три уровня сложности компьютерного соперника.
- Выбор стороны игрока при создании партии.

**Учётные записи и сохранение**
- Регистрация и авторизация пользователей.
- Безопасное хранение парольных хэшей.
- Автоматическое сохранение состояния партии и ходов.
- Продолжение незавершённой игры после повторного входа.
- История партий с результатами и списком ходов.
- Экспорт протокола партии в формат TXT.

## Компьютерный соперник

Для выбора хода реализован алгоритм **Minimax с альфа-бета-отсечением**.

| Уровень сложности | Глубина поиска |
|---|---|
| Лёгкий | 1 полуход |
| Средний | 2 полухода |
| Сложный | 4 полухода |

Оценка позиции учитывает количество простых шашек и дамок, продвижение фигур и контроль центральной части доски.

Альфа-бета-отсечение позволяет исключать из поиска ветви, которые не могут улучшить уже найденное решение.

## Архитектура проекта

Решение разделено на пять проектов:

```text
Russian-checkers/
├── checkers/                  # Графический интерфейс WPF
├── RussianCheckers.Core/      # Правила игры и игровая логика
├── RussianCheckers.AI/        # Minimax и оценка позиции
├── RussianCheckers.Data/      # SQLite, репозитории, авторизация
└── RussianCheckers.Tests/     # Модульные тесты
```

Такое разделение позволяет независимо разрабатывать и проверять игровые правила, компьютерного соперника и работу с данными.

## База данных

Для хранения используется локальная база SQLite, которая создаётся автоматически при запуске приложения.

Основные таблицы:

| Таблица | Назначение |
|---|---|
| `Users` | Учётные записи пользователей |
| `Games` | Параметры, состояние и результаты партий |
| `Moves` | История выполненных ходов |

Состояние игры сохраняется в формате JSON, что позволяет восстановить расстановку фигур, очередь хода и необходимые данные партии.

База данных расположена по пути:

```text
%LocalAppData%\RussianCheckers\checkers.db
```

Для работы приложения не требуется устанавливать отдельный сервер базы данных.

## Безопасность

В приложении предусмотрены базовые механизмы защиты учётных данных:

- PBKDF2-HMAC-SHA256 для хэширования паролей.
- 600 000 итераций и индивидуальная случайная соль.
- Сравнение хэшей с использованием `CryptographicOperations.FixedTimeEquals`.
- Параметризованные SQL-запросы.
- Проверка принадлежности партий текущему пользователю.
- Транзакционное сохранение ходов и состояния игры.

Пароли в открытом виде в SQLite не сохраняются.

## Установка и запуск

### Требования

- Windows x64.
- Visual Studio с поддержкой разработки .NET-приложений для рабочего стола.
- .NET 10 SDK для сборки из исходного кода.

### Запуск из исходного кода

**1. Клонируйте репозиторий:**

```bash
git clone https://github.com/MaxGren/Russian-checkers.git
```

**2. Откройте проект:**

Перейдите в папку `Russian-checkers` и откройте файл решения Visual Studio (`.sln` или `.slnx`).

**3. Соберите приложение:**

Дождитесь восстановления NuGet-пакетов и выполните сборку решения.

**4. Запустите игру:**

Выберите `checkers` в качестве запускаемого проекта и нажмите `F5` или `Ctrl + F5`.

При первом запуске приложение создаст локальную базу данных.

### Запуск опубликованной версии

Для сборки в режиме **Framework-dependent** на компьютере должен быть установлен совместимый **.NET 10 Desktop Runtime**.

## Как играть

1. Зарегистрируйте учётную запись.
2. Выполните вход в приложение.
3. Выберите уровень сложности.
4. Начните новую партию.
5. Выполняйте ходы, выбирая шашку и доступную клетку.
6. При необходимости продолжите сохранённую партию после повторного входа.

В разделе **«История партий»** можно просматривать результаты и ходы, а также сохранять протокол выбранной игры в формате TXT.

## Тестирование

Для проверки основных компонентов предусмотрен отдельный проект `RussianCheckers.Tests`, использующий xUnit.

Проверяются, в частности, генерация допустимых ходов, обязательное взятие, превращение в дамку, алгоритм компьютерного соперника и сериализация игрового состояния.
